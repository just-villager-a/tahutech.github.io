# TahuTech Portfolio

## About the project

TahuTech Portfolio is the personal website of Ade Widyatama Dian Boernama, a .NET and backend software engineer based in Jakarta, Indonesia. It gives recruiters, collaborators, and visitors a clear view of his professional background in one place.

The site highlights his experience building and maintaining web applications, REST APIs, system integrations, and production services with .NET and SQL Server. It also presents his technical skills, employment history, education, contact links, and a selected learning project: a .NET 6 microservices exploration featuring separate Student and Book services, API gateway routing, command/query separation, and asynchronous messaging.
